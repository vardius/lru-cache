## What you get

<CardGrid>
	<Card title="Typed" icon="approve-check">
		`Cache[K, V]` takes any comparable key and any value. `Get` returns a `V` and whether the key was there,
		so a stored zero value is never mistaken for a miss.
	</Card>
	<Card title="Exact LRU order" icon="list-format">
		`Get` and `Set` both count as a use, and the entry evicted is always the least recently used. Tests check it
		against a model cache with random operations.
	</Card>
	<Card title="No allocations after New" icon="rocket">
		`New` makes room for every entry, and a new key in a full cache takes the evicted one's place. With keys of
		strings, numbers or structs of them, nothing allocates after that; tests guard every count.
	</Card>
	<Card title="Safe for concurrent use" icon="padlock">
		One lock guards the cache, and keys are hashed before taking it. A panic on an unhashable key never leaves
		it locked.
	</Card>
	<Card title="Compact" icon="database">
		Entries live in one slice, found through an index of 16 to 32 bytes per entry. The garbage collector scans
		one slice, not an object per entry.
	</Card>
	<Card title="Small API" icon="puzzle">
		`New`, `Get`, `Set`, `Delete` and `Len`. Nothing to configure and no dependencies beyond the standard library.
	</Card>
</CardGrid>

## Evicting without allocating

<div class="landing-lead">

	{evicting.before.allocs} allocations to {evicting.after.ns.toFixed(1)} ns and none.

## Coming from the untagged version

<div class="landing-lead">
	The cache is generic now and its capacity is a number of entries. Nothing returns an error, and `Get` says whether
	the key was there. The untagged version's bugs are fixed: `Set` of an existing key stores the new value.
</div>

<div class="compare">

```go title="untagged"
c, err := lrucache.New("pages", 10*lrucache.MB)
if err != nil {
	return err
}
if err := c.Set("/about", body); err != nil {
	return err
}
body, err := c.Get("/about") // nil if missing
```

```go title="v1"
c := lrucache.New[string, []byte](1000)
c.Set("/about", body)
body, ok := c.Get("/about")
```
